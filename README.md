# Puzzle Playroom

A toddler jigsaw puzzle game for iPad: 6, 9 or 12 big pieces, forgiving snapping, 23 pictures of animals, dinosaurs, ice cream and unicorns, and puzzles from your own photos (press and hold the + card; photos stay on the device).

- `index.html` is the game source.
- `python3 build.py` builds the offline Home Screen web app into `docs/`, which GitHub Pages serves.
